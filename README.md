# OpenCart E-Commerce Website - Manual Testing

## Project Overview
This project focuses on manual testing of an e-commerce
application to evaluate its key customer-facing workflows.

## Objectives
- Validate core application functionality.
- Design positive and negative test scenarios.
- Prepare detailed test cases and test data.
- Execute tests and record actual results.
- Document and track reproducible defects.
- Perform retesting and regression testing.

## Application Under Test
- Application: OpenCart Demo Store
- Testing Type: Manual Testing
- Documentation Tool: Microsoft Excel
- Defect Tracking: Jira (planned)

## Testing Scope
- User Registration
- Login and Logout
- Product Search
- Product Details
- Shopping Cart
- Wishlist
- Checkout
- My Account

## Project Documents
1. Test Plan
2. Test Scenarios

## Project Status
In Progress

## Notes
Test cases and execution results will be updated as testing
progresses. Defects will be documented only after they are
observed and verified.

The project is intended for learning and demonstrating
manual testing practices.
